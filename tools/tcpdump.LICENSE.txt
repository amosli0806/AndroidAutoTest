tcpdump —— 随虫师分发的第三方可执行文件
============================================

文件：tools/tcpdump
来源：从被测车机（arm64-v8a）的 /system/bin/tcpdump 取出，原样随包分发
用途：性能检测页「网络抓包」功能。运行时由 adb push 到设备 /data/local/tmp 后执行，
      不在这台 Windows 电脑上运行（所以它是 Android/ELF 二进制，不是 .exe）。
架构：ELF 64-bit LSB executable, ARM aarch64。设备 CPU 架构不是 arm64 时，
      程序会优先使用设备自带的那份 tcpdump（见 services/packet_capture.py）。

如果设备既没有自带 tcpdump、架构也不是 arm64，请自行准备一份与设备架构匹配的
tcpdump 放到 tools/tcpdump（arm / arm64 / x86 / x86_64 任选其一）。
